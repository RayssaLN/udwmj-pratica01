# Prática 01

## Descrição da Atividade

Usando HTML e CSS, foi desenvolvida uma página Web sobre um assunto de livre escolha, atendendo aos seguintes requisitos:

- A página possui um título e três parágrafos;
- O título e cada parágrafo possuem cores de fonte diferentes;
- Todos os estilos de formatação estão em um arquivo CSS externo, separado do arquivo HTML.

## Tema escolhido

O Mundo da Programação — um breve texto sobre o que é programar, os desafios de aprender a programar e as principais linguagens de programação existentes atualmente.


## Estilos aplicados

| Elemento | Cor aplicada |
|----------|-------------|
| h1 (título) | Azul-escuro (#2c3e50) |
| Parágrafo 1 | Vermelho (#c0392b) |
| Parágrafo 2 | Verde (#27ae60) |
| Parágrafo 3 | Azul (#2980b9) |

O arquivo estilo.css também define a fonte (Verdana) e o fundo da página (#f4f4f4).

## Como executar

1. Baixe os arquivos pagina.html e estilo.css e mantenha-os na mesma pasta;
2. Abra o arquivo pagina.html em qualquer navegador (Google Chrome, Firefox, Edge, etc.);
3. A página será exibida com o título e os três parágrafos, cada um em uma cor diferente, conforme definido no arquivo CSS externo.

## Tecnologias utilizadas

- HTML5
- CSS3
